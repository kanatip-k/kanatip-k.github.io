# Dates shown on project pages

Added 8 November 2026 after inspecting original local project folders and ZIP members. Date labels distinguish original file modification dates from local Git commit history. They are not claimed as confirmed project start/completion dates or proof of personal authorship. Git history may include upstream commits. No GitHub migration/upload dates are used as project dates.

Dates from Git: Emoji Tarot (20 January–16 February 2026), MCP RAG Documentation (24 January–1 February 2026), Project MongoDB (9 February 2025).

Dates from original source files: Foundation Ontology MCP (29 October 2026), Navisworks MCP (2–11 September 2026), IoT Weather Station (3 September 2026), BIM prototype (5 September–3 November 2026), Dorm (29 September 2025).

Dates from original ZIP members: Landslide IoT (27 September 2026), Python Docker Dashboard (26 September 2026).

Dependency/build/cache directories, backup files and unrelated data were excluded. Dorm's starter files with the implausible 1985 timestamp were excluded. Repeated identical timestamps can reflect archive extraction or copying, so file dates are explicitly labelled as such.
